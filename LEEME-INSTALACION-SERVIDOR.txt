      SISTEMA DE GESTION DOCUMENTAL Y CORRESPONDENCIA SOFTCOM
             GUIA DE INSTALACION EN MICROSOFT WINDOWS SERVER
==============================================================================

Este paquete contiene la version completa y precompilada del sistema SoftCom
personalizado para SNOWPOINT HEALTHCARE - CONSULTORA EN SALUD.

------------------------------------------------------------------------------
REQUISITOS DEL SERVIDOR:
------------------------------------------------------------------------------
- Sistema Operativo: Microsoft Windows Server (2016, 2019, 2022) o Windows 10/11 Pro
- Node.js LTS instalado (Descargar de: https://nodejs.org/ - Version 18 o superior)
- 2 GB de memoria RAM minima
- 500 MB de espacio en disco

------------------------------------------------------------------------------
PASOS DE INSTALACION RAPIDA:
------------------------------------------------------------------------------

PASO 1: DESCOMPRIMIR EL PAQUETE
Copie este paquete en el disco de su servidor (ejemplo: C:\SnowPoint o D:\SoftCom).

PASO 2: EJECUTAR EL INSTALADOR
Haga clic derecho en el archivo:
   "1-INSTALAR-EN-SERVIDOR.bat"
y seleccione "Ejecutar como Administrador".

El instalador realizara automaticamente:
- Verificacion de Node.js.
- Apertura de puertos en el Firewall de Windows Server (4000 y 3000).
- Inicializacion limpia de la base de datos (dev.db) con las areas de SnowPoint.
- Compilacion de produccion del Frontend y Backend.

PASO 3: INICIAR EL SISTEMA
Tiene dos opciones para iniciar el sistema:

  OPCION A (Modo Manual):
  Haga doble clic en "2-INICIAR-SOFTCOM.bat".
  El sistema se abrira en: http://localhost:4000

  OPCION B (Modo Servicio de Windows Permanente - RECOMENDADO):
  Haga clic derecho en "3-CONFIGURAR-SERVICIO-WINDOWS.bat" y seleccione
  "Ejecutar como Administrador".
  El sistema se iniciara automaticamente cada vez que el servidor arranque,
  sin necesidad de que un usuario inicie sesion.

------------------------------------------------------------------------------
CUENTA UNICA DE ACCESO INICIAL DE ADMINISTRADOR:
------------------------------------------------------------------------------
- Usuario:    admin
- Contrasena: SnowPoint2026!
- Rol:        ADMINISTRADOR GENERAL
- Area:       Sistemas y Tecnologias en Salud (TI)

------------------------------------------------------------------------------
COMO CREAR CONSULTORES Y PERSONAL DE SNOWPOINT:
------------------------------------------------------------------------------
1. Ingrese con el usuario "admin" en: http://localhost:4000
2. En el menu lateral, haga clic en "Gestion de Personal & Consultores".
3. Presione "Crear Nuevo Consultor / Usuario".
4. Ingrese los datos del consultor (Nombre, Especialidad, Area de Consultoria,
   Usuario, Correo y Contrasena).
5. Al guardar, el consultor podra ingresar inmediatamente desde cualquier 
   equipo de la red para enviar, recibir, derivar y dictaminar expedientes.

------------------------------------------------------------------------------
ACCESO EN RED:
------------------------------------------------------------------------------
Cualquier computadora conectada a la red puede acceder ingresando en su navegador:

   http://[IP_DEL_SERVIDOR]:4000
